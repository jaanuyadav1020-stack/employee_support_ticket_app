# AGENTS.md

## Project Overview
Build an Employee Support Ticket Management App.

## Technology Stack
- React frontend
- Node.js and Express backend
- SQLite database
- REST APIs

## Development Rules
- Follow docs/SPEC.md.
- Follow the approved docs/PLAN.md.
- Keep frontend and backend separate.
- Write clean, readable code.
- Use reusable React components.
- Validate all user inputs.
- Handle API errors properly.
- Never hardcode passwords or secrets.
- Never expose database credentials.

## Testing Rules
- Test every major feature.
- Test invalid and empty inputs.
- Test API endpoints.
- Run tests after every major change.
- Fix defects and re-test.

## Git Rules
- Commit after every working phase.
- Use meaningful commit messages.
- Never commit secrets or generated database files.

## Completion Criteria
- Application runs using README instructions.
- Employee features work.
- Support staff features work.
- Comments work.
- Tests pass.
- No known critical defects.
- README is complete.
